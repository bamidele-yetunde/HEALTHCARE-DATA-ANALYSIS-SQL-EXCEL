# 🏥 Healthcare Data Analysis | SQL & Excel

## 📌 Project Overview

This project focuses on cleaning, transforming, and analyzing a real world healthcare dataset using **SQL and Excel**.

The goal was to improve data quality, standardize inconsistent records, and prepare the dataset for reliable analysis and data driven decision making.

## 🎯 Objectives

* Clean and prepare the healthcare dataset for analysis
* Identify and resolve missing values
* Detect and remove duplicate records
* Standardize inconsistent data formats
* Transform raw data into an analysis ready dataset
* Perform exploratory data analysis
* Identify meaningful trends and patterns

## 🛠️ Tools Used

* SQL
* Microsoft Excel

## 🔍 Data Cleaning Process

The dataset was reviewed and cleaned to address common data quality issues, including:

* Missing values
* Duplicate records
* Inconsistent formatting
* Inconsistent categorical values
* Data type inconsistencies

SQL was used to query, transform, validate, and analyze the dataset, while Excel was used to inspect, organize, and further validate the cleaned data.

## 📊 Analysis

Exploratory analysis was performed to identify patterns and trends within the healthcare data.

The analysis focused on:

* Patient demographics
* Healthcare related records
* Distribution of key variables
* Trends within the dataset
* Potential data quality issues

## 💡 Key Outcomes

* Improved the overall quality and consistency of the healthcare dataset.
* Created a standardized dataset suitable for further analysis.
* Identified trends and patterns through exploratory data analysis.
* Improved data reliability for informed decision making.
